# Qadam AI — помогла подсказка или навредила?

Веб-приложение для врача-реабилитолога. Сравнивает ходьбу ребёнка с ДЦП **до и после подсказки** («выпрями ногу» голосом или в VR) по каждому суставу и показывает цифры, анимацию шага и наблюдения. Решение всегда принимает врач.

> ⚠️ Инструмент поддержки решений, не медицинское изделие. Не ставит диагноз, не определяет тяжесть ДЦП, не назначает лечение, упражнения и лекарства.

## 🚀 Как открыть проект

### Вариант 1. Просто открыть сайт (ничего не нужно устанавливать)

1. Откройте **https://olnni.github.io/qadam-ai/** в Chrome, Edge или Safari (компьютер, планшет или телефон).
2. Слева выберите демо-пациента, например **s61520_16**: сразу видны светофор, анимация шага и выводы ИИ.
3. Язык меняется кнопками **ҚАЗ / РУС** справа вверху.

### Вариант 2. Запустить на своём компьютере

1. Скачайте проект: зелёная кнопка **Code → Download ZIP** на странице репозитория, затем распакуйте архив.
   (Или через git: `git clone https://github.com/Olnni/qadam-ai.git`)
2. Самый простой способ — двойной щелчок по файлу **`index.html`**. Сайт откроется в браузере.
3. Для входа «видео» лучше запустить маленький локальный сервер (нужен [Python](https://www.python.org/downloads/)). В папке проекта откройте терминал и выполните:
   ```bash
   python -m http.server 8000
   ```
   Затем откройте в браузере **http://localhost:8000**.

Интернет нужен только для входа «видео» (модель MediaPipe загружается из интернета) и для шрифта. Всё остальное работает офлайн.

### Как пользоваться (путь врача)

1. **«+ Новый пациент»** → заполните карточку: код (без имени), возраст, вес, рост, длина ноги, какая нога, заметки → «Сохранить».
2. Откроется мастер **«Новая запись»**:
   1. выберите источник: **А) видео**, **Б) датчики**, **В) файл лаборатории** или **Г) демо-пациент**;
   2. загрузите запись **«до подсказки»**;
   3. выберите тип подсказки (голос / VR / другая) и впишите её текст;
   4. загрузите запись **«после подсказки»**;
   5. нажмите **«Запустить анализ ИИ»**: видны настоящие этапы («найдено N кадров → N шагов → ИИ оценил N шагов»).
3. Посмотрите результат: светофор, видео со скелетом, анимация, выводы ИИ, таблица по каждому шагу, графики суставов.
4. Выберите **решение врача**, напишите заметку и нажмите «Сохранить решение». Всё попадёт в историю пациента и на график прогресса.
5. Данные хранятся только в этом браузере. Кнопки «Экспорт / Импорт JSON» в карточке пациента позволяют перенести их на другой компьютер.

**Файлы для проверки** лежат в папке [`examples/`](examples/) (их можно скачать и прямо из мастера):
- `lab_before_s61520_16.csv`, `lab_after_verbal_s61520_16.csv` — источник **В** (лаборатория);
- `sensors_before_SYNTHETIC.csv`, `sensors_after_verbal_SYNTHETIC.csv` — источник **Б** (**синтетика**: склеено из лабораторных шагов, настоящих датчиков у нас нет);
- `wrong_file.csv` — неправильный файл: сайт должен показать понятную ошибку.

### Как снять видео для источника А

- Камера **сбоку**, на уровне таза, неподвижно (лучше на штативе); человек **целиком в кадре**.
- 10–20 шагов при хорошем свете. Можно несколько раз пройти через кадр: сайт сам делит видео на проходы.
- Два видео: «до подсказки» и «после подсказки», снятые **одной камерой с одного места**.
- Видео с iPhone (.MOV, формат HEVC) открываются в Chrome и Edge на Windows и в Safari на Mac.

## Проблема

Врач просит ребёнка сильнее разгибать ногу в бедре. Бедро часто действительно становится лучше, но **таз, колено или стопа могут незаметно ухудшиться**. Шаг длится около секунды, двигаются 4 сустава сразу, а врач смотрит на бедро.

Оценка ИИ на 29 детях из открытых данных KU Leuven (пороги по умолчанию, проверено тестом `tests/test_parity.py`):

| | Голос | VR |
|---|---|---|
| Разгибание бедра улучшилось | 18 из 29 | 19 из 29 |
| **Бедро лучше, но другое хуже** | **11 из 29** | **12 из 29** |
| Помогла без ухудшений | 7 из 29 | 7 из 29 |

Предупреждения получили **16 пациентов**. Пример: у `s61520_16` с голосовой подсказкой бедро лучше на 5,6°, но таз +6,4, колено +4,7. Сильнее всего на оценку повлиял наклон таза в фазе переноса ноги (62–100% шага).

## Где ИИ

| | Что делает | Чьё | Проверка |
|---|---|---|---|
| **ИИ-1** `js/pose.js` | находит суставы на каждом кадре видео, считает углы | MediaPipe Pose Landmarker (Google), готовая модель | геометрия углов — тест (точно); на реальном видео точность **не сверялась с лабораторией** |
| **ИИ-2** `js/gait.js` | делит запись на проходы и шаги, приводит каждый шаг к 51 точке | наш алгоритм | `tests/test_gait.js` |
| **ИИ-3** `js/model.js` | по 204 углам шага оценивает отклонение таза, бедра, колена, стопы (GVS) и GPS | наша модель PCA(15) + Ridge, scikit-learn | Leave-One-Subject-Out |
| **ИИ-4** `js/model.js` | показывает, какой сустав и фаза шага сильнее всего повлияли на оценку | вклад = вес × изменение угла | — |
| ИИ-5 (справка) | похожие походки среди демо-пациентов | 15 главных признаков PCA | только справка |

Не ИИ (это правила): статистика «надёжно» (`|после − до| > 2·√(sd²/n + sd²/n)`), светофор, наблюдения, сообщение родителям.

**Точность ИИ-3** (ошибка ИИ против «угадывания среднего», корреляция; каждый ребёнок проверен моделью, обученной без него):

| | 4 сустава (204 числа) | без таза (153 числа, для видео) | Точность |
|---|---|---|---|
| Таз | 1,32 / 5,07 (r 0,96) | 2,12 / 5,07 (r 0,89) — косвенно | высокая |
| Бедро | 2,33 / 4,72 (0,80) | 2,41 / 4,72 (0,78) | высокая |
| Колено | 2,94 / 4,03 (0,65) | 2,88 / 4,03 (0,67) | средняя |
| Стопа | 2,58 / 3,03 (0,48) | 2,50 / 3,03 (0,52) | низкая |
| GPS | 2,11 / 2,38 (0,54) | 2,07 / 2,38 (0,53) | низкая |

Для видео таз не измеряется: он показан как «ориентир.» и не входит в светофор. Если оценка ИИ выходит за возможные пределы (отклонение < 0), сайт предупреждает, что абсолютным цифрам доверять нельзя.

**Разбиение на шаги** (`node tests/test_gait.js`, 87 синтетических записей, склеенных из настоящих шагов датасета):
- датчики, 60 Гц, шум 0,3°: найдено 93% шагов (теряются неполные шаги в начале и конце), медианная ошибка начала шага 3,6%, светофор совпал в **56 из 58** сеансов;
- видео-путь на идеальных синтетических точках скелета: ошибка начала шага 1,7%, светофор совпал в 52 из 58 (без таза);
- видео из нескольких проходов через кадр: проходы найдены, ошибка начала шага 1,8%.

### Проверка на наших настоящих видео

Мы сняли 3 видео (iPhone, 1280×720, ~20 с, человек 4 раза проходит через кадр): **80** — кривая походка, **81** — исправлено сгибание, но неправильное положение спины, **82** — здоровая походка. Видео не публикуем (на них люди).

| | 80 → 81 | 80 → 82 (здоровая) |
|---|---|---|
| Поза найдена в кадрах | 563/597 → 461/550 | 563/597 → 397/484 |
| Найдено шагов | 8 → 8 | 8 → 6 |
| Колено: отклонение | 11,8 → 6,3 (лучше) | 11,8 → 7,1 (лучше) |
| Стопа: отклонение | 11,2 → 6,1 (лучше) | 11,2 → 7,1 (лучше) |
| Бедро: отклонение | 6,6 → 6,7 (без изменений) | 6,6 → −0,5 (лучше) |

Что это значит: **программа работает на настоящем видео от начала до конца**, и для здоровой походки ИИ показывает меньшие отклонения колена, стопы и бедра, что совпадает с ожиданием. Но часть оценок вышла за возможные пределы (например, −0,5): углы с бытовой камеры отличаются от лабораторных, на которых училась модель. Поэтому видео остаётся **экспериментальным входом**, и для точных цифр нужна проверка вместе с лабораторией. Эта проверка выявила и исправила две ошибки: время кадров MediaPipe между двумя видео и разрывы между проходами через кадр.

**Отброшенная идея:** «ИИ заранее предсказывает, какая подсказка подойдёт ребёнку». На 29 детях (kNN, leave-one-out) это работало хуже правила «всем отвечать нет», поэтому мы её не используем.

## Для разработчиков: обучение и проверки

```bash
pip install pandas scikit-learn numpy playwright
python -m playwright install chromium

python model/train.py          # обучает ИИ, печатает точность, пересоздаёт data/data.js и model/metrics.json
node model/make_examples.js    # пересоздаёт примеры файлов датчиков

python tests/test_parity.py    # JS = Python (разница < 0,02), цифры 18/11/7, 19/12/7, 16
node tests/test_gait.js        # разбиение на шаги и проходы, чтение CSV, геометрия углов
python tests/test_site.py      # сайт в браузере: карточка, мастер, ошибки, казахский, телефон 390 px
python tests/test_video.py                         # видео-путь с MediaPipe (без своего видео)
python tests/test_video.py до.MOV после.MOV --chrome  # ваши видео (iPhone .MOV — через Google Chrome)
```

## Ограничения

- 29 детей одной клиники (Бельгия), ходьба на беговой дорожке, только сагиттальная плоскость одной ноги. Для детей в Казахстане и других условий нужно проверять.
- Видео и датчики — экспериментальные входы. По видео бедро измеряется относительно корпуса, а в лаборатории — относительно таза, поэтому возможен сдвиг. Сравнение «до/после» одной камерой надёжнее абсолютных значений.
- Точность для стопы и GPS ниже.
- Пороги (2°, 2, 1) выбраны командой, их утверждает врач (меняются на странице «Модель ИИ»).
- Данные хранятся только в браузере (`localStorage`), видео никуда не отправляется. Вместо имён — коды.
- Казахский перевод нужно проверить носителю языка.
