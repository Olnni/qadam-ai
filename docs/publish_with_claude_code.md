# Как выложить на GitHub через Claude Code

1. Распакуйте архив `qadam-ai.zip` в удобную папку.
2. Откройте терминал в папке `qadam-ai` и запустите `claude`.
3. Скопируйте Claude Code это задание:

```
Это готовый статический сайт (index.html, без сборки). Сделай следующее:
1. Инициализируй git-репозиторий и сделай первый коммит всех файлов.
2. Создай в моём GitHub новый ПУБЛИЧНЫЙ репозиторий qadam-ai и отправь туда код
   (если gh не авторизован — подскажи, как войти: gh auth login).
3. Включи GitHub Pages из ветки main, корневая папка.
4. Дай мне ссылку на репозиторий и на сайт.
Ничего в коде не меняй.
```

4. Сайт появится по адресу вида `https://ВАШ-ЛОГИН.github.io/qadam-ai/`, обычно через 1–2 минуты.
5. Откройте сайт и проверьте: язык ҚАЗ/РУС, выбор ребёнка, вкладку «Загрузить файлы» с файлами из `examples/`.

**Правки в последний момент** тоже можно делать в Claude Code, например: «поменяй название команды в README» или «сделай заголовок крупнее». После правок попросите: «закоммить и отправь на GitHub».
